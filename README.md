🌡️ Convertidor de Temperaturas

Proyecto sencillo desarrollado con HTML y JavaScript que permite convertir grados Celsius a diferentes unidades de temperatura.

🚀 Funcionalidades

- Conversión de Celsius a Fahrenheit.
- Conversión de Celsius a Kelvin.
- Conversión de Celsius a Rankine.
- Validación de datos introducidos.
- Visualización de resultados en pantalla.

🛠️ Tecnologías utilizadas

- HTML5
- JavaScript

📂 Estructura del proyecto

convertidor-temperaturas/
├── index.html
└── script.js

📐 Fórmulas utilizadas

Conversión| Fórmula
Celsius a Fahrenheit| (°C × 9/5) + 32
Celsius a Kelvin| °C + 273.15
Celsius a Rankine| (°C + 273.15) × 9/5

💻 Uso

1. Descarga o clona este repositorio.
2. Abre el archivo "index.html" en tu navegador.
3. Introduce una temperatura en grados Celsius.
4. Haz clic en el botón Convertir.
5. Visualiza los resultados de las conversiones.
